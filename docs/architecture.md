# 架构设计

```text
Vue 3 案例门户 / 体验工作台 / 管理控制台
                    │
             REST JSON API
                    │
 Spring Boot 案例目录 ─ 案例运行时 ─ 运营统计
                    │             │
       确定性业务规则          可选模型增强
                    │             │
              MySQL 8       DeepSeek / OpenAI 兼容服务
```

## 设计原则

- 本地规则优先：无密钥可运行，关键数值和结论可自动测试。
- 模型只做增强：外部模型用于解释和语言组织，不能覆盖规则计算出的关键数值。
- 故障自动回退：模型超时、鉴权失败或返回格式异常时继续返回本地结果。
- 场景独立扩展：每个案例有独立字段描述和规则处理器，通过统一运行接口暴露。
- 全程可审计：保存案例、输入摘要、结果摘要、运行方式和耗时。
